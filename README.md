# 🦉 English Fun

Site infantil para aprender inglês brincando, em três versões:

| Pasta | Tecnologias | O que tem |
|---|---|---|
| `1-so-html` | só HTML | jogos com `<details>`, formulários validados |
| `2-html-css` | HTML + CSS | telas, correção e estrelas feitas só com CSS |
| `3-html-css-js` | HTML + CSS + JavaScript | 4 jogos, voz em inglês, contas e estrelas salvas no navegador |

Abra o `index.html` de cada pasta no navegador. Com o GitHub Pages ligado, o endereço é
`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/NOME-DA-PASTA/`.
